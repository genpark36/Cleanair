현재 Flutter 앱 건강 모드 구현 요약 (UI 개선 공유용)
작성일 2026-04-05

건강 모드는 홈 화면의 건강 탭에서 열리며, 상단에서 어린이 모드, 고령자 모드, 정화지표 모드 3가지를 전환한다.
데이터가 없으면 공통으로 데이터 없음 카드가 노출된다.

데이터 흐름은 Firestore 실시간 스냅샷 수신 후 Node-RED 동등 엔진으로 health 값을 계산하고, 이 결과를 snapshot 모델로 파싱해 대시보드에 바인딩하는 구조다.
외부 API는 10분 주기로 WAQI/KMA를 조회하며, 체감온도 및 외부 비교 통계에 사용된다.

어린이 모드 카드 순서
1) 호흡기 건강 지수
2) 면역/감염 위험
3) 집중환경 판단
4) 곰팡이 위험도

어린이 모드 핵심 기준
집중환경 CO2 경계값은 700, 1000, 1500 ppm이다.
호흡기 점수는 온도, 습도, TVOC 밴드 감점 합산 방식이다.
감염 위험은 CO2 band와 습도 band의 조합 점수다.
곰팡이 위험은 습도 60% 초과 지속시간과 PM 조건을 함께 본다.

고령자 모드 카드 순서
1) 심혈관 보호점수
2) 심혈관 리스크
3) 쾌적 수면지수
4) 실외 체감온도

고령자 모드 핵심 기준
심혈관 보호점수는 PM 고노출 시간과 k 평균을 사용한다.
수면지수는 양호 CO2 비율 70%와 양호 VOC 비율 30% 가중 방식이다.
체감온도는 외부 기상 데이터 기반 값으로 표시된다.

정화지표 모드 카드 순서
1) 정화속도 k 카드(듀얼 또는 단일)
2) CADR-Index 카드
3) IPI 위험지수 카드
4) 환기 지표 카드

정화지표 핵심 기준
k는 5분 슬라이딩 윈도우 로그 선형 회귀로 추정한다.
최소 샘플은 15개다.
PM 회귀는 노이즈 임계(0.99) 미만이면 스킵된다.
CADR 등급 기준은 k>=2.0 S, k>=1.0 A, k>=0.5 B, 그 미만 C다.
IPI는 CO2 k 기반으로 t90과 레벨을 산출한다.

현재 확인된 주의 포인트
첫째, IPI 최고 점수 4가 UI 색상 매핑에서 누락될 가능성이 있다.
둘째, 환기 상태 문자열이 엔진과 fallback UI 사이에서 서로 다를 수 있다.
셋째, 건강 모드 정보 페이지는 정적 문서라 런타임 로직 변경 시 내용이 어긋날 수 있다.
넷째, 일부 카드의 색상 판정이 문자열 포함 매칭 기반이라 문구 변경 시 오분류 위험이 있다.

UI 개편 우선순위 제안
1) IPI 점수 4 표시 체계 보완
2) 환기 상태 enum 단일화
3) 정보 페이지와 실제 로직 동기화 체계 마련
4) 위험도 시각화 로직을 문자열 매칭에서 enum 기반으로 전환

오른쪽 비교 탭 상세 설명 (실외 비교 전용)
비교 탭은 실내 센서값과 실외 기준값(API/측정소)을 나란히 비교하는 화면이다.
핵심은 절대값 자체보다 "실외 대비 편차"를 보여주는 것이다.

비교 대상 지표
- PM2.5
- 온도
- 습도

비교 제외 지표
- CO2, TVOC, NOx (설명 카드에 비교 미제공으로 표시)

출처
- PM2.5: 에어코리아
- 온도/습도: 기상청

상태별 화면
1) 현재 데이터 없음
- 중앙에 "데이터 없음" 표시

2) 현재 데이터는 있으나 외부 비교 데이터 없음
- 중앙에 "외부 데이터 불러오는 중..." 표시
- 보조 문구: AQICN(PM2.5), 기상청(온도/습도) 조회 중 안내
- 원형 로딩 인디케이터 표시

3) 정상 상태
- 카드 순서: 측정소 정보 카드 -> 지표 비교 카드들 -> 통계 설명 카드

측정소 정보 카드
- 제목: 가장 가까운 측정소
- 본문: 측정소명 + 부제
- 업데이트 시간: HH:mm 형식

지표 비교 카드 구성
1) 헤더: 지표명, 출처 라벨
2) 값 박스 2개: 센서 측정값 / API(출처)
3) 편차 라인: "편차 ±값 단위" + 추세 아이콘
4) 통계 블록(있을 때만): 오차율(MAPE), 일치도(R2), RMSE, 변동(CV), 표본 수

편차 및 추세 규칙
- sensor - station > 0: 상승 아이콘, 빨강 계열
- sensor - station < 0: 하강 아이콘, 파랑 계열
- 같거나 계산 불가: 중립 아이콘
- delta 문자열이 없으면 앱이 직접 diff를 계산해 표시

통계 강조 규칙
- MAPE < 10%면 초록 강조
- R2 > 0.8이면 초록 강조

하단 통계 설명 카드 내용
1) 지표 뜻 설명: R2, RMSE, 상대오차
2) R2 신뢰도 기준
- 0.9 이상 매우 높음
- 0.8~0.9 높음
- 0.7~0.8 보통
- 0.6~0.7 낮음
- 0.6 미만 매우 낮음
3) 데이터 출처 안내
- PM2.5는 에어코리아
- 온도/습도는 기상청
- CO2/TVOC/NOx는 실내 센서 자체 측정(비교 분석 없음)

실무 활용 포인트
- 환기 후 실내값이 외부값에 수렴하는지 확인
- PM/온습도 편차를 통해 실내 환경 제어 상태 점검
- 장기 편차로 센서 이상 가능성 1차 점검
