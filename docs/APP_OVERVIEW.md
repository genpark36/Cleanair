# Cleanair 앱 설명

Cleanair는 실내 공기질을 확인하고, 필요한 경우 환기 장치나 스마트 플러그를 제어하며, 화재가 의심될 수 있는 이상 패턴까지 확인하는 앱입니다. 단순히 센서값을 숫자로 보여주는 앱이 아니라, 센서와 위치, 알림, 플러그, 웹 상황판을 하나의 흐름으로 묶는 것을 목표로 했습니다.

## 1. 전체 구성

Cleanair는 네 부분이 함께 동작합니다.

| 구성 | 역할 |
| --- | --- |
| AirGradient 센서 | 실내 공기질 데이터를 측정 |
| Flutter 앱 | 센서 등록, 실시간 확인, 알림 설정, 플러그 제어 |
| Firebase | 센서 데이터 저장, 알림, 방재 판단, 플러그 명령 처리 |
| 웹 상황판 | 여러 센서와 플러그를 지도에서 확인하고 원격으로 대응 |

사용자는 앱에서 센서를 등록하고 위치를 저장합니다. 이후 센서가 Firebase로 데이터를 보내면 앱과 웹 상황판이 같은 데이터를 읽어 현재 상태를 보여줍니다.

## 2. 처음 사용하는 흐름

1. 앱을 설치합니다.
2. AirGradient 센서에 제출용 펌웨어를 설치합니다.
3. 앱에서 센서를 PIN 또는 mDNS로 등록합니다.
4. 센서가 설치된 공간과 위치를 저장합니다.
5. 메인 화면에서 실시간 공기질을 확인합니다.
6. 필요한 경우 Tasmota 플러그를 등록합니다.
7. 알림과 방재모드를 켜고 실제 동작을 확인합니다.

이 흐름이 끝나면 앱은 등록된 센서의 최신 데이터를 계속 읽고, 공기질 상태와 알림, 플러그 제어 상태를 함께 보여줍니다.

## 3. 메인 대시보드

메인 화면은 현재 공간의 공기질을 빠르게 확인하는 곳입니다.

주요 기능은 다음과 같습니다.

- 통합 공기질 지수 확인
- PM2.5, CO2, TVOC, NOx, 온도, 습도 확인
- 현재 위치 또는 등록 위치 표시
- 최근 경보 상태 확인
- 건강 인사이트와 방재 상태로 이동

통합 공기질 지수는 여러 측정값 중 문제가 되는 항목을 중심으로 계산합니다. 단순 평균을 쓰지 않는 이유는, 한 항목만 크게 나빠져도 실제 사용자는 환기나 대응이 필요하기 때문입니다.

## 4. 상세 화면

상세 화면은 공기질 변화를 시간 흐름으로 보는 곳입니다.

확인할 수 있는 내용은 다음과 같습니다.

- 10분, 1시간, 6시간, 24시간, 주간, 월간 그래프
- 특정 구간의 최대값, 최솟값, 평균, 중앙값
- 센서 데이터 로그
- CSV 파일 저장

CSV 파일은 Android 기준으로 아래 폴더에 저장됩니다.

```text
Download/AirGradient
```

## 5. 건강 모드

건강 모드는 공기질을 생활 관점에서 다시 해석합니다.

예를 들어 PM2.5는 호흡기 부담과 관련이 크고, CO2는 환기 상태를 판단하는 데 도움이 됩니다. 습도는 곰팡이 위험과 수면 쾌적성에 영향을 줍니다. 앱은 이런 값을 묶어 어린이, 고령자, 집중 환경, 수면, 정화 속도 같은 항목으로 보여줍니다.

정화속도 k는 오염물질이 얼마나 빠르게 줄어드는지 보기 위한 값입니다. 공기청정기나 환기팬을 켠 뒤 농도가 빠르게 내려가면 정화속도 k가 높게 나타납니다.

## 6. 비교와 히트맵

비교 화면은 실내 센서값과 외부 공식 측정소 데이터를 함께 보는 화면입니다.

확인할 수 있는 내용은 다음과 같습니다.

- 주변 공식 측정소 값
- 등록 센서 값
- 지도 기반 PM2.5, NOx/NO2, CO 등 표시
- 선택한 측정소 또는 센서의 값 비교

실내 공기질이 나쁠 때 외부도 나쁜지, 아니면 실내에서만 문제가 생긴 것인지 구분하는 데 도움이 됩니다.

## 7. 알림

앱은 사용자가 선택한 기준에 따라 알림을 보냅니다.

일반 공기질 알림은 항목별로 받을 수 있고, 방재 알림은 더 강한 단계부터 받을 수 있도록 설정할 수 있습니다. 흔한 공기질 변화까지 모두 알리면 사용자가 알림을 무시하게 되므로, Cleanair는 알림 민감도를 조절할 수 있게 했습니다.

앱이 꺼져 있어도 Firebase Cloud Messaging을 통해 알림을 받을 수 있습니다.

## 8. 스마트 플러그

Tasmota 플러그를 등록하면 앱과 웹 상황판에서 전원을 제어할 수 있습니다.

주요 기능은 다음과 같습니다.

- ON/OFF 수동 제어
- 자동/수동 모드 전환
- 플러그 상태 표시
- 전압, 전류, 전력 표시
- 제어 이력 확인
- 제어 이력 CSV 저장
- 공기질 기준에 따른 자동 제어

자동 제어는 기준을 넘으면 켜고, 회복 기준 아래로 내려가면 끄는 방식입니다. ON 기준과 OFF 기준을 분리해 둔 이유는 측정값이 기준 근처에서 흔들릴 때 플러그가 계속 켜졌다 꺼지는 현상을 줄이기 위해서입니다.

## 9. 방재모드

방재모드는 공기질 악화와 화재 의심 상황을 구분하기 위한 기능입니다.

요리, 먼지, 환기 부족처럼 흔한 상황에서도 PM2.5나 TVOC가 오를 수 있습니다. 그래서 Cleanair는 한 번의 높은 수치만 보고 바로 위급으로 판단하지 않습니다. 현재값, 최근 변화량, 여러 지표가 동시에 나빠졌는지, 일정 시간 이상 지속되는지를 함께 봅니다.

방재모드에서 확인할 수 있는 내용은 다음과 같습니다.

- 현재 방재 상태
- PM2.5, TVOC, CO2, NOx, 온도, CO 관측값
- 화재 의심 또는 CO 위험 판단
- 센서와 플러그 위치
- 상황 요약 공유
- 119 전화 화면 열기
- 웹 상황판으로 상황 전송

CO 센서값이 들어오는 경우에는 CO 위험 판단도 함께 표시됩니다. 현재 AirGradient ONE 기본 센서 구성에는 CO 센서가 없으므로, CO 값이 없을 때는 해당 항목이 `-` 또는 `N/A`로 표시됩니다.
기판에 CO 센서를 납땜하여 추가하는 것으로, 정확도를 강화할 수 있습니다.

## 10. 웹 상황판

웹 상황판은 앱에서 전송한 상황을 더 큰 화면에서 확인하기 위한 화면입니다.

사용 예시는 다음과 같습니다.

1. 사용자의 휴대폰 앱에서 위험 상황을 감지합니다.
2. 사용자가 상황을 웹 상황판으로 전송합니다.
3. 웹 상황판에서 위치, 센서값, 연결 장치를 확인합니다.
4. 필요하면 플러그를 원격으로 제어합니다.
5. 현장 확인 후 상황을 종료합니다.

소방서나 관리자가 직접 자동 신고를 받는 완성형 공공 시스템은 아니지만, 시설 관리자나 발표 시연자가 “상황을 전달받고 판단하는 화면”으로 사용할 수 있습니다.

## 11. 사용자가 얻는 것

Cleanair가 제공하려는 가치는 세 가지입니다.

첫째, 센서값을 그냥 숫자로 보지 않고 현재 공간이 어떤 상태인지 쉽게 판단할 수 있습니다.

둘째, 공기질이 나쁠 때 알림과 플러그 제어까지 이어져 실제 대응을 할 수 있습니다.

셋째, 일반 공기질 악화와 방재 의심 상황을 분리해 더 중요한 알림에 집중할 수 있습니다.

즉, Cleanair는 실내 공기질을 “보고 끝나는 시스템”이 아니라, 확인하고 판단하고 대응하는 시스템으로 구성되어 있습니다.
