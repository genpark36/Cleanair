# 최종 점검표

제출 전 아래 항목을 한 번씩 확인합니다.

## 앱

- APK 설치가 정상적으로 끝난다.
- 첫 실행 시 초기 설정 화면이 열린다.
- 알림 권한을 허용할 수 있다.
- 센서 PIN 등록이 된다.
- mDNS 등록이 된다.
- 센서 위치를 저장할 수 있다.
- 메인 화면에 실시간 센서값이 표시된다.
- 상세 그래프가 열린다.
- CSV 파일이 `Download/AirGradient` 폴더에 저장된다.
- 건강 모드가 열린다.
- 비교 화면에서 측정소와 히트맵이 표시된다.
- 설정 화면에서 알림과 권한 상태를 확인할 수 있다.

## 플러그

- 플러그를 등록할 수 있다.
- 같은 Wi-Fi에서 로컬 HTTP 제어가 된다.
- MQTT 설정 후 외부 제어가 된다.
- ON/OFF 버튼이 실제 플러그 상태를 바꾼다.
- 자동 제어 설정을 저장할 수 있다.
- 전압, 전류, 전력 값이 표시된다.
- 제어 이력이 남는다.
- 제어 이력을 CSV로 저장할 수 있다.

## 방재모드

- 방재 홈에서 현재 상태가 표시된다.
- 분석 화면에서 주요 관측값과 판단 결과가 표시된다.
- 상황판에 등록 센서와 플러그 위치가 표시된다.
- 방재 대비 화면에서 센서와 플러그 연결 상태를 확인할 수 있다.
- 위험 상황을 웹 대시보드로 전송할 수 있다.
- 상황 종료가 앱 또는 웹에서 반영된다.

## 웹 상황판

- `https://capstone-cleanair-2026.web.app` 접속이 된다.
- Google 로그인이 된다.
- 등록된 센서가 표시된다.
- 등록된 플러그가 표시된다.
- 지도에서 센서와 플러그 정보를 열 수 있다.
- 플러그 ON/OFF 제어가 된다.
- 긴급 상황 배너가 표시된다.
- 상황 상세를 열고 닫을 수 있다.
- 상황 종료가 된다.
- 플러그 제어 이력을 CSV로 저장할 수 있다.

## 백엔드

- Firebase Functions 배포가 완료된다.
- 센서 데이터가 Firestore에 들어온다.
- 앱에서 FCM 토큰이 등록된다.
- 알림 설정이 저장되고 다시 읽힌다.
- 경보 조건에서 알림이 온다.
- 앱이 꺼져 있어도 백그라운드 알림이 온다.
- MQTT worker가 플러그 명령과 응답을 처리한다.
